부동산디지털블록체인 REAL8 — 신규 사이트 (기존 사이트와 별도 보관)

1. 이 폴더의 index.html, app.js, styles.css, supabase-config.js 파일을 새로운 GitHub 저장소 real8-new에 업로드합니다.
2. GitHub Settings → Pages에서 main 브랜치, /(root)로 게시합니다.
3. Supabase Authentication → URL Configuration에서 새 사이트 주소를 Redirect URLs에 추가합니다.
4. Supabase Authentication → Providers에서 Email 인증 발송 및 확인 설정을 점검합니다.
5. 데이터베이스 테이블, RPC 함수, Storage 버킷과 RLS 정책은 기존 사이트의 설정을 사용합니다. 이 파일만으로 자동 생성되지 않습니다.
6. 기존 Supabase 프로젝트를 공유하므로 기존 데이터에 영향을 줄 수 있습니다. 완전히 독립된 운영을 원하면 신규 Supabase 프로젝트 및 DB 스키마/정책 이관이 필요합니다.
7. 관리자 권한은 profiles.role = admin인 계정만 화면에 표시됩니다. 실제 보안은 반드시 Supabase RLS 및 RPC 서버측 권한 검사로 시행해야 합니다.
8. 네이버/카카오 로그인, 전화번호 인증, 실제 코인/NFT 발행은 아직 구현되지 않았습니다. 별도 공급자 설정·서버 작업·법적 검토가 필요합니다.
9. 본 패키지는 별도 주소에서 검증하기 위한 첫 신규 버전이며, 실제 로그인/등록/보상 동작은 배포 후 시험해야 합니다.

기존 GitHub 저장소 realestate-site는 수정하거나 삭제하지 마세요.
